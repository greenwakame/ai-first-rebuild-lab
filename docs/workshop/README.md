# ワークショップ

## 目的

このプロジェクトの開発を、実際に手を動かして体験してもらうための会です。説明を聞くだけで終わらせず、**当日中に実際のIssueへ着手し、Pull Requestを1本出すところまで**を目標にします。

体験してもらいたいのは、次の3つです。

- AIコーディングエージェントに実装させながら、生成された差分を自分で検証する進め方
- 設計判断をADRとして記録し、後から追えるようにする文化
- 「コードが生成されただけでは完了ではない」という検証の規律

## 対象者

- このプロジェクトへの参加を検討している方
- Next.js / Rust / PostgreSQL のいずれかに関心がある方
- AIエージェントを使った開発プロセスに関心がある方

社内メンバー、有志、自己学習目的の方を区別しません。特定言語の実務経験は前提にしませんが、Gitの基本操作（clone、branch、commit、push）とターミナル操作に慣れていることを想定しています。

## 扱うデータ

**当日扱うのは合成データだけです。** メンバー名や写真なども、この用途のために作った架空のデータです。実在する人物の情報や、実際に運用されていたデータは使いません。機密情報の取り扱いを心配する必要はありません。

## 当日のゴール

参加者それぞれが次の状態になることを目指します。

1. ローカルで開発環境が起動し、`mise run doctor` が通っている
2. 担当するIssueについて合意している
3. 実装し、リポジトリの検証コマンドが通っている
4. Pull Requestを1本提出している

マージは当日中とは限りません。レビューを経てからになります。

## 所要時間

半日程度（プロジェクト説明から Pull Request 提出まで）を想定しています。環境構築でつまずくと大きく時間を取られるため、[prerequisites.md](prerequisites.md) の事前準備を必ず済ませてから参加してください。

## 当日の流れ

[agenda.md](agenda.md) を参照してください。

## 実際にどんな作業をするのか

過去に実際にクローズされたIssueを1件取り上げ、着手からマージまでの流れを再現した資料を用意しています。当日の作業イメージが最もつかみやすい資料です。

→ [issue-walkthrough.md](issue-walkthrough.md)

## 参加方法

このリポジトリのDiscussionsの「ワークショップ」カテゴリで開催を告知します。事前質問・当日のQ&Aも同カテゴリで受け付けます。

開発参加そのものの申込は [../how-to-join.md](../how-to-join.md) を参照してください。ワークショップ参加者には当日限定の一時アクセスをお渡しし、継続参加の意思と実績を確認したうえで、privateリポジトリへのcollaborator招待をご案内します。

- macOSが動作するノートPC
- 安定したネットワーク接続
- [prerequisites.md](prerequisites.md) の事前準備が完了していること
