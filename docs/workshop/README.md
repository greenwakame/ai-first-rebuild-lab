# ワークショップ

このプロジェクトの開発を、実際に手を動かして体験してもらうための会です。説明を聞くだけで終わらせず、**実際のIssueへ着手し、Pull Requestを1本出すところまで**を目標にします。

> [!NOTE]
> **当日扱うのは合成データだけです。** メンバー名や写真なども、この用途のために作った架空のデータです。機密情報の取り扱いを心配する必要はありません。

## 既存ワークショップとの関係

このプロジェクトは、社内で続いてきた技術ワークショップの**新しい題材**として発足しました（[経緯はこちら](../../README.md#なぜこのプロジェクトが始まったか)）。

**従来の題材と併存します。** どちらに取り組むかは選べます。「設計を先に固め、レビューを通してから実装する」という教わってきたことは共通で、この題材ではそこに **AIエージェントによる実装と、人による検証** が加わります。

## 持ち帰ってほしいこと

- [x] AIコーディングエージェントに実装させながら、**生成された差分を自分で検証する**進め方
- [x] 設計判断をADRとして記録し、後から追えるようにする文化
- [x] 「コードが生成されただけでは完了ではない」という検証の規律

## 当日のゴール

**到達点は人によって違って構いません。** 環境構築まででも、その日の学びとしては十分です。

| # | 到達点 | 確認方法 |
| --- | --- | --- |
| 1 | 開発環境が動く | `mise run doctor` が通る |
| 2 | 進め方が分かる | 担当するIssueの**完了条件を自分の言葉で説明できる** |
| 3 | 実装して検証できた | エージェントの差分を読み終え、`mise run check` が通る |
| 4 | Pull Requestを提出した | **確認できなかったことも書けている** |

> [!IMPORTANT]
> **マージは当日中とは限りません。** レビューを経てからになります。

## 1日で終わる想定です

**1回の参加で 4 まで到達できるよう設計しています。** そのために事前準備をお願いしています。

一方で、**複数回参加すると別の学びがあります。** 1回目は手順をなぞるだけで精一杯でも、2回目以降は「なぜこの完了条件なのか」「この差分は本当に正しいか」を自分で判断できるようになります。設計判断の質は、繰り返さないと見えてきません。継続して参加される方には、より踏み込んだIssueをご案内します。

## 当日の流れ

所要時間は**丸1日**です。時刻は開催ごとに調整するため、ここでは順序と目安の長さを示します。

| 区分 | 内容 | 目安 |
| --- | --- | --- |
| 開始 | 受付・自己紹介・プロジェクト説明 | 30分 |
| | 初参加の方への説明／継続参加の方は作業開始 | |
| **午前の作業** | 環境構築 → Issue選定 → 着手 | |
| 区切り | **進捗報告** | 10分 |
| 休憩 | 昼休憩 | 60分 |
| **午後の作業** | 実装 → 差分の検証 → `mise run check` | |
| 区切り | **進捗報告**・小休憩 | 15分 |
| **仕上げ** | Pull Request の作成 → レビュー | |
| 締め | 最終報告・振り返り | 60分 |

各工程の詳しい内容は [agenda.md](agenda.md) を参照してください。

### 進捗報告について

**区切りのタイミングで、全員が進捗を報告します。** 何にどこまで進んだか、どこで詰まっているかを共有する時間です。

AIエージェントを使う開発では、**手が止まっていることが外から見えにくくなります。** エージェントに投げたまま停滞していても、画面上は動いているように見えるためです。定期的に言語化することで、早めに助けを求められるようにしています。

報告の形式や記入例は、**招待後にお渡しする資料**で説明します。

## 対象者

- このプロジェクトへの参加を検討している方
- Next.js / Rust / PostgreSQL のいずれかに関心がある方
- AIエージェントを使った開発プロセスに関心がある方

社内メンバー、有志、自己学習目的の方を区別しません。特定言語の実務経験は前提にしませんが、**Gitの基本操作**（clone、branch、commit、push）と**ターミナル操作**に慣れていることを想定しています。

## 準備について

> [!WARNING]
> **環境構築でつまずくと大きく時間を取られます。** [prerequisites.md](prerequisites.md) の事前準備を必ず済ませてから参加してください。**AIコーディングエージェントのアカウントが必要**で、費用は自己負担です。

**リポジトリの構築は、開催前に済ませておくことを推奨します。** Rustのツールチェイン導入とローカル環境の起動を含むため、当日に始めると午前を使い切ることがあります。開催前に招待をお送りしますので、事前に構築しておいてください。

**当日その場で構築することもできます。** 事前に間に合わなかった場合はサポートしますので、参加を諦めないでください。ただしその日はゴール1〜2までになる可能性があります。

当日お持ちいただくもの:

- [ ] 次のいずれかが動作するノートPC（管理者権限があること）
  - macOS
  - Windows 11 + WSL2（Ubuntu 24.04）
- [ ] 安定したネットワーク接続
- [ ] [prerequisites.md](prerequisites.md) の事前準備が完了していること

WindowsではWSL2（Ubuntu）内で開発コマンドを実行します。ネイティブWindows（PowerShell）での
開発手順は対象外です。

## 質問について

**詰まったら早めに聞いてください。** 1人で抱えたまま時間を使うのが、当日いちばんもったいない状態です。

質問するときは、次を添えていただけると解決が早くなります。

- 何をしようとしていたか（目的）
- 何を試したか
- どうなったか（エラーメッセージがあればそのまま）

事前の質問はDiscussionsの「**ワークショップ**」カテゴリへ、当日の質問はその場で受け付けます。

## 参加方法

このリポジトリのDiscussionsの「**ワークショップ**」カテゴリで開催を告知します。

開発参加そのものの申込は [how-to-join.md](../how-to-join.md) を参照してください。ワークショップ参加者には当日限定の一時アクセスをお渡しし、継続参加の意思と実績を確認したうえで、privateリポジトリへのcollaborator招待をご案内します。
