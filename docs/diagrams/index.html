認証・認可の trust boundary

ブラウザから PostgreSQL までのあいだで、どこに境界があり、各所で何を検証し、 何をブラウザへ渡さないかを 1 枚にまとめた図です。

この図の読み方

テーマ切り替え、検索、関係のたどり、拡大縮小、画像の書き出しが図の中で動きます。 図と ADR が食い違う場合は、ADR が正です。

図は型付きの仕様から機械的に生成しており、生成のたびに同じ結果になることを確認しています。 配置や線の重なりは生成時に自動検証しています。
