この図の読み方

図は型付きの仕様から機械的に生成しており、生成のたびに同じ結果になることを確認しています。配置や線の重なりは生成時に自動検証しています。

図は補助であり、判断の正は ADR にあります。食い違う場合は ADR が正です。
