## 実行した確認

- `pnpm check`: TypeScript、ESLint、スキーマテスト、素材の存在・SHA-256照合、絵コンテ生成が成功。
- 正式入力と文言・配色の変更入力が有効。必須項目欠落、未対応種類、ID重複、負・小数の尺、合計尺違い、見出し・要素名の過長、リモート素材、パストラバーサル、HTML、実行コード用の未知フィールド、表示URLの不一致、fps違いの14種類を拒否。
- `pnpm variant`: 冒頭の文言とミント・青を変更したJSONから、別のMP4と静止画を生成。画像で変更を確認。正式JSONは変更せず、その後に正式版を再出力。
- `pnpm verify`: ffprobeで上記映像仕様を検証。全1800フレームをFFmpegでデコードし、エラーなし。
- 全1800フレームを160×90のグレースケールへ変換し、輝度70/255を超える画素がないフレームを検出する検査を実施。該当0フレーム。この検査は完全な空白検出の保証ではない。
- 同じ入力のフレーム1000を2回PNGへ描画し、SHA-256が一致。動きはフレームと固定数値だけから計算し、実時刻・スクロール・非固定乱数に依存しない。
- `scene-1.png`〜`scene-6.png`、幅640pxずつの `scenes.png` を目視確認。日本語の欠落、見出しの切れ、要素同士の重なりなし。中心メッセージが縮小状態でも読める。
- 冒頭0/1/30、場面境界225/450/900/1350/1575の直前・開始・15フレーム後・42フレーム後、1740/1799を静止画確認。枠が収束する際の色の急変と文字への接近を修正して再出力。
- 実MP4から約0.5秒間隔で抽出した全編の `motion-1.png`〜`motion-3.png` を目視確認。意味のある順序で枠と光点が移動し、最後に静止へ収束。タイトルのフェードと枠の変形は意図した演出。

## 実再生と画像確認の区別

ローカルGoogle Chrome（headless、Playwright駆動）のHTML videoで、幅640px・速度1倍・シークなしで30秒の全編を自動再生した。30秒地点で `ended=true`、再生時間の実測30.25秒、総フレーム1800、ブラウザが報告したdropは1フレーム。約0.5秒ごとの60件のmediaTimeサンプルを記録した。終了画面も画像で確認。詳細は `out/browser-playback.json` と `out/browser-playback-end.png`。

これは全編の自動再生確認。連続動画を人が鑑賞して演出を評価した、とは報告しない。見た目は6場面・転換前後・全編の抽出画像による確認。Safari、Firefox、QuickTime、スマートフォンでの実再生は未確認。ブラウザのdrop 1フレームはMP4にフレーム欠落があることを示すものではなく、ファイル自体の1800フレームはすべてデコードできている。
